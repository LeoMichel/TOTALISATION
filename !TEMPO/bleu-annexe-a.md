# Annexe A : Le carnet du praticien N5 et les gabarits remplis

Le praticien du niveau 5 a une matière première nouvelle : la relation. Ses fiches documentent les liens tissés avec les utilisateurs réels, les effets observés, les décisions prises sur la base d'un retour humain. Le carnet du praticien N5 est le carnet du praticien N4 enrichi d'une colonne : le retour humain.

## Le carnet du praticien N5 (un document, six fiches)

1. La fiche de contact (chaque contact réel : nom, rôle, contexte, périmètre)
2. La fiche de visite (chaque visite observation : ce qui a été vu, ce qui a été dit, ce qui a été évité)
3. La fiche d'effet (chaque effet observé en réel : la donnée croisée avec le témoignage)
4. La fiche d'incident (chaque incident réel : ce qui s'est passé, ce qui a été ressenti, ce qui a été décidé)
5. La fiche de demande (chaque demande implicite entendue : ce qui n'a pas été dit mais ressentait)
6. La fiche de revue mensuelle (la revue des liens : quels contacts sont vivants, quels liens sont morts)

## La fiche de contact remplie (extrait réel)

```
CONTACT — Marie-Claude, infirmière-chef, 3e étage, CHU
Rencontre le : 18/09 à 14h (unité 3B)
Rôle : utilisatrice quotidienne du module de planification
Contexte : 22 lits, 14 infirmières, 2 rotations hebdomadaires
Périmètre : le module de planification (pas le reste du produit)

CE QU'ELLE DIT :
« Le module est bien. Je l'utilise tous les matins. Mais quand
je dois échanger deux quarts avec Sylvie, je le fais par
téléphone — le module ne le permet pas. »

CE QU'ELLE NE DIT PAS (mais qui ressort) :
Elle a connu trois versions du module en deux ans. Elle a
appris à ne pas se plaindre : « On nous a dit que ce serait
amélioré. » Elle ne croit plus au « ce sera amélioré ».

ARTEFACT OBSERVÉ : un cahier manuel à côté de l'ordinateur.
Elle y note les échanges de quarts, à la main. Le cahier est
l'outil réel de planification des échanges — le module est
l'outil officiel.

DÉCISION DU PRATICIEN :
Le cahier est un miroir : il documente un besoin réel non
couvert (l'échange de quarts entre deux personnes). Ce besoin
est réel, non documenté dans le backlog, et non couvert par
le produit. Action : ajouter au backlog « échange de quarts
entre deux personnes » avec la priorité de la demande réelle.
```

## La fiche de visite remplie

```
VISITE OBSERVATION — 25/09, 2 heures, unité 3B, CHU
Observateur : L.M.   Observé : le début de poste (7h-9h)

7h00 : Marie-Claude ouvre le module. 6 clics pour arriver à
la liste des quarts du jour. Elle connaît les 6 clics par
cœur — elle les fait sans regarder l'écran.

7h03 : elle consulte le cahier manuel. 3 échanges de quarts
à planifier. Elle appelle Sylvie par téléphone (le module
n'a pas de fonction d'échange).

7h11 : elle note l'échange dans le cahier. Elle modifie le
module : suppression du quart de Sylvie, ajout de son propre
nom. 14 clics. Elle vérifie 3 fois que le module n'a pas
provoqué d'erreur.

7h15 : elle ouvre le cahier et écrit une note : « Sylvie ok
pour échange, confirmé par tél. 07h12. »

CE QUE LA VISITE MONTRE :
Le module couvre la vue (consultation des quarts) mais pas
l'action (l'échange entre deux personnes). Le cahier couvre
l'action. L'utilisateur vit dans les deux outils — le module
pour la vue, le cahier pour l'action. C'est une frontière
entre l'outil officiel et l'outil réel — et c'est exactement
ce que le praticien N3 sait détecter.
```

## La fiche d'effet remplie

```
EFFET — Réduction du temps de planification, mesuré ET observé
Mesuré le : 02/10   Observé le : 25/09 (la visite)

LA DONNÉE (mesurée) :
Temps moyen de planification d'une semaine : 42 min → 28 min
(mesuré par les timestamps du module, sur 6 semaines).

LE TÉMOIGNAGE (observé) :
Marie-Claude : « Avant, je passais une heure le vendredi à
préparer la semaine. Maintenant c'est une demi-heure. Mais
je passe encore 20 minutes au téléphone pour les échanges. »

LA CROISEMENT :
La donnée confirme le témoignage (le temps a baissé). Le
témoignage nuance la donnée (le temps d'échange n'a pas
baissé — il n'est pas couvert par le produit). Sans la visite,
la donnée aurait dit « succès ». Avec la visite, la donnée
dit « succès sur la vue, pas sur l'action ».

DÉCISION :
La corrélation signal→résultat (divergences → taux de retour)
est confirmée par le terrain. Mais le taux de retour ne
mesure pas ce que les utilisateurs vivent réellement : la
prochaine mesure N5 sera « temps passé hors produit » (le
cahier, le téléphone), mesuré par observation, pas par
le système.
```

## La fiche de revue mensuelle remplie

```
REVUE MENSUELLE DES LIENS — 30/09        Animateur : L.M.

| Contact | Vivant ? | Dernier contact | Lien |
|---------|----------|-----------------|------|
| Marie-Claude (3B) | OUI | 25/09 | visite + confiance |
| Jean-Pierre (1A) | OUI | 22/09 | mail + satisfaction |
| Sylvie (3B) | MOU | 12/09 | indirect (via M-C) |
| Unité 2C | NON | — | pas de contact |

DÉCISIONS :
1. Unité 2C n'a jamais été contactée : c'est une équipe qui
utilise le produit sans lien avec l'équipe. Action : une
visite d'observation avant le 15/10 (priorité de la relation,
pas de la fonction).
2. Sylvie est un lien mou : elle est connue indirectement.
Action : un contact direct avant le 31/10.

TEST : la revue a produit 2 décisions. ✓
```

## La fiche de mesure manuelle remplie

```
MESURE MANUELLE — Temps passé hors produit
Définie le : 04/10    Première mesure : 11/10    Fréquence : mensuelle

CE QU'ELLE RÉVÈLE : le temps que les utilisateurs passent en
dehors du produit pour faire ce que le produit ne couvre pas.
C'est une mesure de la frontière entre le produit et la
pratique — la frontière que le praticien N3 détecte, mais
que le niveau 4 ne mesure pas.

MÉTHODE : observation directe (pas d'auto-déclaration —
les utilisateurs surestiment ou sous-estiment leur temps).
L'observateur note, pendant 2 heures d'observation, chaque
passage hors produit : le cahier, le téléphone, le tableur.

DÉBUT : l'ouverture du module (le début de la tâche).
FIN : la fermeture du module (la fin de la tâche).
HORS PRODUIT : tout le temps entre les deux qui n'est pas
dans le module (le cahier, le téléphone, le tableur, la
conversation informelle).

PREMIÈRE MESURE (11/10, unité 3B, 2 heures d'observation) :
Temps hors produit : 34 minutes sur 120 minutes (28%).

CE QUE ÇA DIT :
Un utilisateur passe 28% de son temps de planification
HORS du produit. Le produit couvre 72% de la tâche. Les
28% restants sont le besoin réel non couvert — le cahier,
le téléphone, les échanges. C'est la mesure la plus honnête
du niveau 5 : elle mesure ce que le produit ne fait pas.

RISQUE D'ABUS : utiliser cette mesure pour justifier le
remplacement du produit par le cahier (le cahier est plus
simple pour les échanges). Ce n'est pas le but : le but est
de couvrir le besoin réel — dans le produit ou hors produit,
mais avec une décision explicite.
```

## Les dialogues types du praticien N5

### Dialogue 1 : avec un utilisateur qui ne dit pas

```
PRATICIEN : « Vous utilisez le module tous les jours ? »
UTILISATEUR : « Oui, tous les matins. »
PRATICIEN : « Et il vous convient ? »
UTILISATEUR : « Oui... c'est bien. »
PRATICIEN : « (silence — 15 secondes) »
UTILISATEUR : « ... je passe encore du temps au téléphone
pour les échanges. Le module ne le fait pas. »

CE QUE CE DIALOGUE MONTRE : la question directe produit la
réponse polie. Le silence produit la vérité. Le praticien qui
sait se taire entend ce que le praticien qui parle n'entend
pas — c'est le même principe que la mesure manuelle du
praticien N4 : la donnée qui ne se mesure pas ne se voit pas.
```

### Dialogue 2 : avec un sponsor qui ne demande pas

```
SPONSOR : « Le produit est bon, les chiffres sont bons.
Qu'est-ce qui vous manque ? »
PRATICIEN : « Rien ne me manque. Mais il y a une chose que
je n'ai pas osée vous dire : le cahier manuel de Marie-Claude.
Elle planifie les échanges à la main, à côté du produit.
28% de son temps est hors produit. »
SPONSOR : « Et vous ne l'avez pas dit avant ? »
PRATICIEN : « Je ne savais pas comment le dire sans donner
l'impression que le produit avait échoué. »
SPONSOR : « Le produit n'a pas échoué. Il a découvert une
frontière. C'est son travail. »

CE QUE CE DIALOGUE MONTRE : le praticien qui craint de
décevoir le sponsor cache la vérité. Le sponsor qui accueille
la vérité libère le praticien. C'est une relation — pas un
rapport. C'est le niveau 5.
```

## Le bilan de vitalité du niveau 5 (le gabarit)

```
BILAN DE VITALITÉ N5 — Équipe [nom]    Trimestre : [dates]

| Question | Réponse | Preuve |
|----------|---------|--------|
| Combien de contacts réels ce trimestre ? | [N] | le carnet |
| Combien de visites d'observation ? | [N] | les fiches |
| Combien de mesures manuelles ? | [N] | les fiches |
| Combien de demandes implicites entendues ? | [N] | les fiches |
| Combien de liens morts identifiés ? | [N] | la revue |
| Combien de décisions prises sur retour humain ? | [N] | le backlog |
| Quel est le temps hors produit moyen ? | [%] | la mesure |

RÈGLE D'ÉCRITURE : chaque réponse est accompagnée d'une
preuve (artefact, décision datée, observation). Une réponse
sans preuve est une impression — et les impressions ne
mesurent pas la vitalité.
```

## Le test de la collection pour le praticien N5

Le praticien qui documente les liens documente sa relation au réel. Le praticien qui documente les décisions documente sa relation au sponsor. La collection demande les deux — mais commence toujours par les liens, parce que sans lien réel, la décision est une hypothèse.

Le niveau 5 n'est pas un niveau de plus. C'est le retour à la source : le praticien qui a construit un système fiable retourne voir les personnes qui l'utilisent — et découvre que la frontière qu'il a documentée n'était pas la seule. C'est le niveau 5 : la lucidité qui ne s'arrête pas à la frontière du système, parce que la vraie frontière est celle du produit et de la pratique — et elle ne se mesure pas en systemes, elle se mesure en personnes.
