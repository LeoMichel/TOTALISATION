# Partie 21 : Les rituels du praticien prédictif

Ce que le praticien fait chaque jour, chaque semaine, chaque mois, chaque trimestre — sans y penser. Les rituels sont les habitudes qui font la prévention réelle (pas les formalités du niveau 6).

## Le rituel quotidien (5 minutes)

**Ce que le praticien fait** : ouvrir le registre, lire les valeurs de la veille, vérifier les seuils. Si une valeur approche un seuil (marge < 20 %), noter la tendance. Si une valeur dépasse un seuil, ouvrir l'investigation.

**Ce que le praticien ne fait pas** : interpréter les valeurs (c'est la lettre de veille qui interprète), modifier les seuils seul (c'est la revue de seuils), agir sur les alertes seul (c'est l'équipe qui porte).

**Pourquoi 5 minutes** : plus de temps, et le praticien devient le gardien de l'outil — moins de temps, et le rituel n'existe plus.

## Le rituel hebdomadaire (30 minutes)

**Ce que le praticien fait** : écrire la lettre de veille. Les valeurs observées vs les seuils, les marges, les évolutions, les alertes avec action formulée, la conclusion. Envoyer la lettre à l'équipe (pas au manager — à l'équipe).

**Ce que le praticien ne fait pas** : écrire la lettre pour l'équipe (la lettre appartient à l'équipe), omettre les marges (sans marge, la valeur est un chiffre), envoyer la lettre sans action (une alerte sans action est une inquiétude).

**Pourquoi 30 minutes** : la lettre tient sur une page. Une page de plus, et personne ne la lit. Une page de moins, et les marges disparaissent.

## Le rituel bihebdomadaire (60 minutes)

**Ce que le praticien fait** : conduire l'atelier de prévention. Le tour des signaux (10 min), le tri (10 min), le choix (5 min), la pose (10 min), la clôture (3 min). 1–2 chantiers de prévention posés max, avec porteur et échéance.

**Ce que le praticien ne fait pas** : transformer l'atelier en revue d'incidents (la revue d'incidents est un autre rituel), poser plus de 2 chantiers (aucun ne sera fait), porter les chantiers lui-même (le porteur est l'équipe).

**Pourquoi 60 minutes** : l'atelier de prévention est un exercice d'équipe — pas un compte rendu. Moins de temps, et l'atelier devient une formalité. Plus de temps, et l'équipe s'ennuie.

## Le rituel mensuel (90 minutes)

**Ce que le praticien fait** : la revue des chantiers de prévention. Pour chaque chantier ouvert : la progression, la preuve attendue, la morsure mesurée (si livré). Pour chaque chantier livré : la morsure documentée dans la mémoire.

**Ce que le praticien ne fait pas** : reporter les chantiers sans discussion (un chantier reporté deux fois est abandonné — et documenté comme tel), masquer les morsures nulles (une prévention sans morsure est une dépense), porter les chantiers à la place des porteurs.

**Pourquoi 90 minutes** : la revue est le moment où les préventions deviennent réelles (les morsures documentées) ou disparaissent (les chantiers abandonnés, documentés). Moins de temps, et les chantiers s'accumulent sans vérification.

## Le rituel trimestriel (2 heures)

**Ce que le praticien fait** : la revue des seuils. Pour chaque seuil : est-ce qu'il a été franchi ? Est-ce qu'il a été trop large (aucun dépassement) ou trop étroit (dépassements fréquents sans incident) ? Ajuster les seuils avec l'équipe — pas seul.

**Ce que le praticien ne fait pas** : ajuster les seuils seul (le seuil appartient à l'équipe), abaisser les seuils pour "faire des alertes" (une alerte sans action est une inquiétude), supprimer les seuils jamais franchis (un seuil jamais franchi est une information — il documente que la pratique est saine).

**Pourquoi 2 heures** : les seuils vivent avec l'équipe. Un seuil figé est un seuil mort. La revue trimestrielle est le moment où les seuils s'ajustent à la réalité.

## Le rituel semestriel (2 heures)

**Ce que le praticien fait** : la revue de la mémoire. Pour chaque entrée : est-ce qu'elle est encore appliquée ? Les règles actives sont-elles encore vivantes ? Les entrées obsolètes sont archivées (pas supprimées — l'archivage documente l'obsolescence). Les entrées redondantes sont fusionnées.

**Ce que le praticien ne fait pas** : supprimer les entrées obsolètes (l'archivage documente, la suppression efface), garder les entrées que personne n'applique (une entrée non appliquée est une formalité — documenter et archiver), fusionner les entrées seul (la fusion est une décision d'équipe).

**Pourquoi 2 heures** : la mémoire vivante est la mémoire qui se relit. Une mémoire jamais relue est un dépôt — et un dépôt ne prévient rien.

## Le rituel annuel (3 heures)

**Ce que le praticien fait** : le bilan annuel prédictif (gabarit Annexe D). Ce qui s'est passé (les incidents évités, les morsures documentées), ce qui n'a pas marché (les chantiers abandonnés, les seuils déréglés, les entrées obsolètes), ce qui a été transmis (les porteurs, les praticiens formés, les rituels tenus par l'équipe sans le praticien).

**Ce que le praticien ne fait pas** : célébrer sans mesurer (les morsures documentées, pas les intentions), cacher les échecs (les chantiers abandonnés, les seuils déréglés), s'attribuer la prévention (la prévention appartient à l'équipe — le praticien l'a facilitée).

**Pourquoi 3 heures** : le bilan annuel est le moment où le praticien vérifie que la prévention est réelle (l'équipe la fait sans lui) — ou qu'elle dépend encore de lui (la faute du praticien centralisateur).

## La règle des rituels

**Les rituels sont les habitudes, pas les formalités.** Un rituel est réel quand : il se tient sans le praticien (l'équipe le fait), il produit des documents vivants (les lettres, les morsures, les entrées), et il s'ajuste (les seuils, les entrées, les chantiers). Un rituel est une formalité quand : il se tient parce que le praticien le tient, il produit des documents morts (personne ne les relit), et il ne s'ajuste jamais.

**Le test du praticien** : prenez deux semaines de congé. Les rituels tiennent-ils ? Si oui, la prévention est réelle. Si non, la prévention est un praticien — pas une discipline.
