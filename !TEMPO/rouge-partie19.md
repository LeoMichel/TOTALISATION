# Partie 19 : Les gabarits remplis consolidés — le carnet du praticien

Les six fiches du praticien du niveau 1 (Partie 11) existent en version vide pour l'usage quotidien. Cette partie les consolide en version imprimable — un carnet que le praticien imprime, utilise en atelier, et archive au centre d'excellence.

## Le carnet du praticien N1 (un seul document, six fiches)

**Page de titre :**

```
CARNET DU PRATICIEN N1
Équipe : [nom]        Semaines : [S1 - S8]
Praticien : [nom]     Coach : [nom]
```

**Les six fiches, dans l'ordre d'usage :**

1. La fiche de spécification (avant le code, chaque demande)
2. La fiche de bug (chaque bug priorisé)
3. La grille Go/No-Go (chaque livraison)
4. La fiche de confirmation (1 à 4 semaines après chaque diffusion)
5. Le registre des décisions (chaque décision de cérémonie)
6. Le tableau de bord minimal (chaque vendredi)

**L'ordre d'usage n'est pas l'ordre de numérotation :** c'est l'ordre du cycle (éliciter, définir, planifier, implémenter, diffuser, confirmer). Le praticien qui suit le cycle trouve chaque fiche au bon moment.

## Le rituel de remplissage

**Pendant l'atelier, pas après.** Chaque fiche est remplie pendant l'atelier qui la concerne — jamais après. Une fiche remplie après l'atelier est un souvenir ; pendant, c'est une preuve.

**Archivage au centre d'excellence :** chaque fiche complétée est archivée avec sa date. Six mois plus tard, les fiches archivées sont l'historique de l'équipe — et la preuve de sa progression.

**Le test du carnet :** si le praticien ne remplit pas les fiches pendant les ateliers, le carnet est mort — et la méthode est une conversation en l'air. Le test : montrez-moi vos fiches archivées de la semaine 4.

## Le gabarit de confirmation rempli (extrait réel)

```
CONFIRMATION — Version 2.3 (rapport X)    Date : 17 juillet
Demandeur : P.G.  Élicitation : DEM-2024-098

CRITÈRES DE SUCCÈS :
1. « Comprendre le résultat d'une combinaison de filtres »
   → atteint (P.G. démontre la combinaison attendue)
2. « Les chiffres concordent avec l'outil comptable »
   → partiel (concordent sauf pour les postes annulés — non élicité)
3. « Utilisé par les 3 équipes sans formation »
   → partiel (2 équipes sur 3 ; la 3e utilise encore l'export Excel)

USAGE RÉEL :
- Utilisé comme prévu : filtre simple, export mensuel
- Utilisé autrement : le filtre « colonne vide » est utilisé pour
  trouver les enregistrements incomplets (usage non prévu, utile)
- Non utilisé : la sauvegarde de filtres (personne ne l'a trouvé)

CE QU'ON APPREND :
1. Le critère « postes annulés » n'avait pas été élicité — l'élicitation
   doit inclure le traitement des enregistrements annulés.
2. La 3e équipe n'a pas été formée ; l'export Excel est son point
   d'entrée → prochaine élicitation : demander l'outil actuel AVANT
   de proposer.

AJUSTEMENTS : ticket DEM-2024-124 (postes annulés) ; question
d'outillage pour la découverte des fonctions (la sauvegarde existe
mais est invisible).
```

**Ce que ce gabarit rempli confirme :** la confirmation n'est pas une enquête de satisfaction — c'est une machine à apprendre. Les trois apprentissages ci-dessus ont modifié deux élicitations suivantes et un choix d'outillage — c'est la grande boucle en action.

## Le carnet comme transmission

Le carnet du praticien N1 est le premier document qu'un nouveau reçoit à son intégration. Il n'est pas une documentation : c'est un guide d'usage — chaque fiche y est expliquée par un exemple rempli, pas par une théorie.

Le nouveau qui lit le carnet apprend en trois étapes : ce qu'il doit remplir (le gabarit), comment ça se remplit (l'exemple), et ce que ça produit (la preuve). Ces trois étapes valent mieux que n'importe quel document de formation — parce qu'elles sont l'expérience d'une équipe, pas une instruction d'un expert.

Le praticien qui transmet son carnet transmet son expérience. Le praticien qui transmet la méthode transmet une théorie. La collection demande les deux — mais commence toujours par le premier.
