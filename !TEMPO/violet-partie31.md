# Partie 31 : Le calendrier de lecture annuel du niveau 7

La lecture annuelle du niveau 7 est différente de celle des autres niveaux : elle ne construit pas un système — elle entretient une culture. Les relectures ne sont pas des entraînements de rituels : elles sont des respirations de philosophie.

| Période | Relecture | Pourquoi |
|---|---|---|
| Semaines 1-8 | Les parties dans l'ordre | Installer les rituels culturels |
| Mois 3 | Les 7 rituels (Partie 7) + les fiches 31-32 | Ancrer les rituels dans la pratique |
| Mois 4 | Le vécu du praticien (Partie 8) + les situations difficiles (Partie 12) | Survivre aux premières tensions philosophiques |
| Mois 5 | Les exercices E1-E6 non faits + les fiches 33-34 (réconciliation) | Le trimestre de consolidation |
| Mois 6 | L'audit de vitalité (E12) + la trousse de premiers secours (Partie 13) | Le point de contrôle semestriel |
| Mois 7-9 | Une fiche par semaine + les gabarits remplis (Partie 26) | L'entretien par répétition espacée |
| Mois 10-12 | La transmission (Partie 10, l'exercice fondateur culturel) + le bilan annuel | Devenir le porteur de la culture |
| Fin d'année | La révision de la philosophie (rituel 6) + l'épilogue du praticien (fiche 31) | La grande respiration annuelle |

La spécificité du niveau 7 : la relecture annuelle de la philosophie. Chaque année, le praticien relit la philosophie documentée (vision, valeurs, jurisprudence, récits) et se pose la question : cette philosophie parle-t-elle encore de nous ? Si oui : elle est vivante. Si non : la révision annuelle (rituel 6) est le moment de la faire évoluer.

La relecture de la philosophie n'est pas une formalité : c'est l'audit annuel de la conviction. Une philosophie qui ne survit pas à sa relecture annuelle n'est pas une philosophie : c'est une aspiration.

# Annexe A : Le gabarit de réconciliation d'apprentissages

**Usage :** quand deux apprentissages semblent contradictoires — le format de l'arbitrage documenté. **Rappel d'architecture :** le geste complet de réconciliation (documenter ce qui est, décider ce qui devient, tracer ce qui est décidé) est le sujet du livre 2 — *Toute la différence par la réconciliation du LEGACY*. La fiche ci-dessous traite l'arbitrage léger : deux apprentissages qui mesurent des choses différentes, dans des contextes différents.

**Structure du gabarit :**

```
ARBITRAGE D'APPRENTISSAGES — [n]  Cré le : [date]

APPRENTISSAGE A : « [formulation] »
Source : [personne/équipe/contexte]

APPRENTISSAGE B : « [formulation] »
Source : [personne/équipe/contexte]

LA TENSION (pourquoi ils semblent contradictoires) :
________________________________________________________

L'INVESTIGATION (ce que chaque apprentissage mesure vraiment :
dans quel contexte A a-t-il été appris ? dans quel contexte B ?)
- A a été appris dans : [contexte]
- B a été appris dans : [contexte]

L'ARBITRAGE (l'apprentissage qui subsume les deux, ou
la règle de bascule entre les deux) :
________________________________________________________

SI LA TENSION EST CULTURELLE (deux pratiques héritées, deux
représentations du métier, un legacy de méthodes) :
→ renvoyer au livre 2 : la réconciliation du LEGACY. L'arbitrage
léger ne suffit pas quand ce qui s'affronte sont deux passés.

LE NOUVEL APPRENTISSAGE (relié aux deux sources) :
→ MEM-[n]
```

**L'exemple rempli (les 40 heures / 1 heure) :** voir Partie 26, Gabarit 4.

## Annexe B : Les gabarits de gabarits — la méta-méthode

Les gabarits de la collection ne sont pas des prescriptions : ce sont des points de départ. Chaque organisation les adapte à son contexte, les améliore, les corrige. Voici le gabarit de gabarits — la méta-méthode pour adapter n'importe quel gabarit.

```
ADAPTATION DE GABARIT — [nom du gabarit original]  Cré le : [date]
Adapté par : [nom]    Contexte : [votre organisation]

CE QUE LE GABARIT ORIGINAL FAIT BIEN (à garder tel quel) :
________________________________________________________

CE QUE LE GABARIT ORIGINAL NE COUVRE PAS (à ajouter) :
________________________________________________________

CE QUE LE GABARIT ORIGINAL SURDIMENSIONNE (à simplifier) :
________________________________________________________

CE QUE VOTRE CONTEXTE DEMANDE DE PLUS :
________________________________________________________

LE GABARIT ADAPTÉ : (le gabarit modifié, en entier)

TEST DE RÉUSSITE : (comment savoir si le gabarit adapté fonctionne)
________________________________________________________

DATE DE RÉVISION : [quand revoir si ça fonctionne]
```

**La règle de l'adaptation :** le gabarit adapté n'est pas un remplacement — c'est une variante. Les deux coexistent : le gabarit original pour les contextes standards, la variante pour votre contexte. Et la variante peut retourner dans la collection si elle sert à d'autres organisations.

## Annexe C : Le gabarit de correction de la collection

**Usage :** documenter une erreur dans la collection (une pratique qui ne fonctionne pas comme décrit, un seuil mal forgé, un gabarit mal conçu) — et la proposer comme correction.

```
CORRECTION PROPOSÉE — [n]            Cré le : [date]
Par : [nom]    Contexte : [votre organisation]

LA PRATIQUE CONCERNÉE : [la pratique, le seuil, le gabarit]

CE QUE LA COLLECTION DIT :
________________________________________________________

CE QUE J'AI OBSERVÉ (le réel, chiffré si possible) :
________________________________________________________

POURQUOI ÇA NE FONCTIONNE PAS DANS MON CONTEXTE :
________________________________________________________

LA CORRECTION PROPOSÉE (la pratique ajustée) :
________________________________________________________

TEST DE LA CORRECTION (comment savoir si elle fonctionne mieux) :
________________________________________________________

DATE DE RÉVISION : [quand revoir]
```

**La règle de la correction :** une correction qui fonctionne dans votre contexte n'est pas un remplacement de la collection — c'est une variante contextuelle. Les deux coexistent : la collection originale pour les contextes standards, la correction pour votre contexte. Et la correction peut enrichir la collection si elle sert à d'autres organisations.
