# BLUEPRINT DE PRODUCTION — Les 7 livres Guidance vers 45 000+ mots

> Document maître de production. Chaque livre Guidance suit cette architecture.
> Fondations pédagogiques : modèle 3-to-1 (3 exercices d'application par séance de formation),
> pratique délibérée (objectif explicite + feedback immédiat + répétition), répétition espacée.

## L'objectif de contenu

**45 000 mots par livre = ~220 pages = ~180 pages de lecture réparties sur un an de pratique.**

Un lecteur qui pratique une guidance est un lecteur qui travaille : chaque section doit
lui donner quelque chose à faire, à mesurer, à prouver. Le contenu se répartit en 6 familles :

| Famille | Volume cible | Nature |
|---|---|---|
| F1. Les 8 semaines (ateliers opérationnels) | ~15 000 mots | Ateliers numérotés : objectif, durée, participants, étapes, livrable |
| F2. Formation (modules F1-F8) | ~6 000 mots | Séances formatées avec déroulé minuté en tableaux |
| F3. Exercices d'entraînement (E1-E12) | ~6 000 mots | Exercices autonomes avec grille de correction |
| F4. Évaluation (grilles + tests) | ~4 000 mots | Grilles de maturité, évaluations individuelles, tests de niveau |
| F5. Cas réels + gabarits remplis | ~7 000 mots | La mission Faucon, ACAQ/Opal-RT, exemples remplis |
| F6. Annexes opérationnelles (A1-A8) | ~7 000 mots | Gabarits, checklists, calendriers, glossaire, cérémonies |

## Le calendrier de lecture d'un an

Chaque livre est conçu pour être **pratiqué sur 8 semaines**, puis **entretenu sur l'année**.
La table de lecture annuelle (par livre) :

| Période | Contenu | Temps de lecture |
|---|---|---|
| Semaines 1-8 (le parcours) | Parties 1-3 (8 semaines) + Partie 4 | ~3 h/semaine |
| Mois 3-4 (consolidation) | Partie 5 (cas, gabarits) + révision des capsules | ~2 h/semaine |
| Mois 5-6 (approfondissement) | Partie 6 (situations difficiles) + exercices non faits | ~2 h/semaine |
| Mois 7-9 (entretien) | Annexes A1-A8 utilisées en rituel + répétition espacée des capsules | ~1 h/semaine |
| Mois 10-12 (transmission) | Le lecteur devient formateur : utilise les modules F1-F8 | ~1 h/semaine |

Cette structure justifie le volume : **le livre est un carnet de route annuel**, pas un
roman qu'on lit une fois.

## Les 20 gabarits d'unités de contenu

Chaque unité suivante est un gabarit réutilisable. Le remplissage est mécanique une fois
la matière identifiée (ACAQ + vécu + mission).

1. **Atelier** : objectif, durée, participants, matériel, étapes numérotées, livrable,
   pièges, variante
2. **Capsule du vécu** : situation, tension, décision, leçon, lien avec l'atelier
3. **Module de formation** : durée, public, matériel, déroulé minuté (tableau), critère
   de réussite, piège classique
4. **Exercice d'entraînement** : consigne, ce que l'exercice révèle, grille de correction
5. **Grille d'évaluation** : lignes (éléments), colonnes (niveaux), preuve requise
6. **Gabarit rempli** : le document vide + l'exemple rempli annoté
7. **Cas vécu étendu** : situation, conflit, résolution, enseignements, variante
8. **Situations difficiles** : symptôme, diagnostic, ce qui a fonctionné, ce qui n'a pas
   fonctionné
9. **Variantes contextuelles** : petite équipe, distribuée, legacy, réglementée, sponsor
   sceptique, reprise
10. **Cérémonie adaptée** (depuis ACAQ) : nom, objectif, quand, participants, préparation,
    déroulé, sorties, pièges, variantes
11. **Fiche-outil** : nom, usage, format, exemple rempli
12. **Checklist de rituel** : les cases cochables avant/pendant/après
13. **FAQ** : question, réponse honnête, lien
14. **Anti-pattern** : le symptôme, pourquoi ça arrive, le remède
15. **Le test de fin de niveau** : les questions, les réponses attendues/mauvaises
16. **Glossaire d'entrée** : terme, définition de l'équipe, source
17. **Table de correspondance** : élément ↔ preuve ↔ responsable ↔ fréquence
18. **Étude de cas quantitative** : les chiffres avant/après, la méthode de mesure
19. **Lecture continue** : le calendrier annuel du lecteur
20. **Plan de formation de l'équipe** : la séquence des modules pour former les nouveaux

## Le rythme de production

Chaque session de travail produit une famille de contenu complète pour un livre.
La matière ACAQ étant extraite, chaque cérémonie adaptée = ~600-800 mots de contenu
authentique adapté au niveau. L'ordre recommandé :

1. ROUGE (le plus proche de la cible, le premier lu)
2. ORANGE
3. JAUNE → VERT → BLEU → INDIGO → VIOLET

## La règle de qualité

Chaque unité de contenu produite doit passer le test : **« le lecteur peut faire quelque
chose avec, aujourd'hui, dans son équipe »**. Si une section ne donne rien à faire, à
mesurer, à prouver, elle est de la prose — elle est coupée ou transformée.
